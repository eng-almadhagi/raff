# النسخة الثابتة — 0.6

هذا دليل الإصدار السابق. للنسخة متعددة المصادر 0.7 استخدم [دليل التشغيل الحالي](multisource-runbook.md) و[تقريرها](multisource-review-2026-10-06.md).

مسار الموقع الجديد هو `site/`. يعمل البحث بالمعنى والنص الكامل داخل المتصفح باستخدام Web Worker وTransformers.js وONNX/WASM. لا يحتاج الموقع المنشور Python أو Docker أو API أو خادم تطبيق. Python أداة إعداد/اختبار قبل النشر فقط. ملفات المسارات نسبية، وتُختبر النسخة تحت `/raf/` لتناسب صفحات مستودعات GitHub.

## التجربة على الجهاز الحالي

النسخة المبنية: `private/pages-preview/raf/`. لا تُرسل إلى مستودع عام؛ تشمل الكتاب والنموذج والفهارس.

```powershell
Set-Location 'D:\رف'
.\.venv\Scripts\python.exe -m http.server 8010 --bind 127.0.0.1 --directory private/pages-preview
```

افتح http://127.0.0.1:8010/raf/ . هذا خادم ملفات للاختبار فقط؛ لا ينفذ استرجاعًا أو إجابات. استضافة GitHub Pages تحل محله عند النشر. لا يصلح فتح `index.html` عبر `file://` لتشغيل Worker وfetch.

## بناء النسخة وإضافة كتاب

يستمر مسار الاستيراد والفهرسة الموحّد الموجود في المشروع. لا يعاد جلب الكتاب عند البناء أو عند السؤال. بعد استيراد إصدار وفهرسته واختباره:

```powershell
.\.venv\Scripts\python.exe -m tools.build_pages --database var/local-research.sqlite3 --book fatawa-islamiyyah-1708
node --test --test-isolation=none tests/pages.test.mjs
node tools/check_pages.mjs
```

يصدّر الأمر جميع الوحدات، مع فصل الملفات لكل `book_id` داخل `data/`. يُضاف الكتاب إلى `catalog.json` دون إزالة الكتب الأخرى. تبديل الكتاب ينهي العامل السابق ويفتح فهرس الكتاب المحدد فقط. يلزم نموذج الفهرس نفسه E5 بمقاس 384؛ النماذج الأخرى تحتاج دعمًا واختبارًا منفصلًا.

يعيد البناء استخدام النموذج المحلي ومكتبة Transformers المحفوظة. `tools/pages_runtime.py` يوفر تنزيل أصول المتصفح من npm/Hugging Face بإصدارات وبصمات مثبتة عند تجهيز جهاز جديد/بناء CI. لا ينزّل أي نص ديني. `tools.setup_model` يجهز نموذج أدوات الفهرسة المحلية.

## النشر لاحقًا

لم يُنفّذ نشر عام، ولم يثبت التشغيل على نطاق GitHub فعلي حتى الآن. فحص المسار الفرعي وخادم الملفات هو محاكاة للبيئة الثابتة، وليس شهادة نجاح النشر.

1. حسم إذن توزيع النص والفهرس؛ كل ما يُرسَل للمتصفح قابل للتنزيل. استضافة ثابتة لا تخفي المحتوى أو مفاتيح API.
2. اعتماد الإصدار علميًا واجتياز بوابة التقييم القائمة. `--public` يرفض إصدار البحث الحالي.
3. تصدير إصدار معتمد باستخدام `tools.build_pages --public --database ... --book ... --output ...`؛ ثم وضع `catalog.json` و`vocabulary.json` و`data/` فقط في `pages-content/`. يحتوي كل كتاب `approval.json` صادرًا من manifest الإصدار المعتمد. هذا المجلد متجاهَل في Git افتراضيًا، ولا يضاف عمدًا إلا بعد حسم النشر.
4. تفعيل Pages بمصدر GitHub Actions وتشغيل `Deploy approved static Raf` يدويًا. يفشل البناء إن كان المحتوى ناقصًا أو تجريبيًا؛ لا ينشر واجهة فارغة باعتبارها موقعًا مكتملًا.
5. CI يجمع الملفات الثابتة وينزّل النموذج المثبت أثناء البناء ثم يرفع ناتج `_site`. ملف النموذج نحو 118 MB، لذلك لا يوضع في Git العادي. لا تدخل أدوات Python أو Docker ضمن ناتج الموقع.
6. اختبار الرابط العام الفعلي، بما فيه التحميل الأول والبحث والجوال ومصدر كل إجابة، قبل إعلان اكتمال النشر.

الأصول تُحمّل من الموقع نفسه؛ سياسة CSP تمنع الاتصالات الخارجية أثناء تشغيل البحث. روابط المراجع لا تُفتح إلا باختيار المستخدم. النموذج يقارب 136 MB مع tokenizer، والفهارس والكتاب وWASM تزيد التحميل؛ يلزم متصفح حديث وذاكرة مناسبة. لم يُختبر جهاز هاتف مادي ضعيف حتى الآن.

## طريقة الإجابة والحدود

- جواب قصير كامل: نقل حرفي من جواب الفتوى، مع قيوده، ومصدره. لا إعادة صياغة مولّدة ولا API مدفوع.
- جواب طويل أو مجموعة: مقتطف افتتاحي معلن أنه غير مكتمل، وزر النص الكامل. **لم يتحقق بعد تقديم ملخص مباشر موثوق لكل سؤال وكل فتوى طويلة**؛ لا نخفي هذا القصور بتسمية المقتطف ملخصًا.
- الأدلة المستخرجة: نصوص محددة بعلامات اقتباس أو أقواس مع عبارات نسبة؛ تحفظ مقاطع المصدر نفسها. الكشف ليس شاملًا لكل أساليب كتابة الأدلة. لا يُعد تحقيقًا لصحة الحديث أو مطابقة الآية للمصحف.
- الاقتراحات: فتاوى موجودة، تقاربها دلالي مع اشتراك في موضوع العنوان؛ تفتح الموضع الأصلي مباشرة.
- ستة مواضع ناقصة في النسخة المستوردة محفوظة وقابلة للتصفح، لكنها لا تبني جوابًا. اكتمال السجلات لا يثبت اكتمال النص في الطبعة الأصلية.

ملفات `raf/` و`web/` وخيارات Docker باقية للاسترجاع والأدوات السابقة؛ **ليست جزءًا من تشغيل نسخة Pages**. لا تحذفها على أنها متطلبات للموقع المنشور.

# نشر الكود وإتاحة بيانات البحث

المستودع المطلوب: https://github.com/eng-almadhagi/raff . ربط Git ورفع الكود أمران منفصلان عن نشر موقع يعمل ببياناته. لا تُنشر واجهة فارغة بوصفها النسخة المكتملة.

أعيد فتح [تعريف IslamQA](https://islamqa.info/en/about-us) و[سياسة الخصوصية](https://islamqa.info/en/privacy-policy) يوم 6 أكتوبر 2026؛ يظهر حفظ الحقوق ولم نجد فيهما منح إعادة توزيع عام. صفحة [تراث](https://turath.io/) تحيل إلى التطبيق ولم تقدم في الصفحة المفتوحة نص ترخيص للكتاب. راجع الأدلة وحدود الفحص في [حقوق الكتاب](fatawa1708-rights.md)، و[حقوق IslamQA والمسابقة](source-rights-2026-10-06.md)، و[فحص الدرر](dorar-rights-review.md). غياب الإذن الواضح ليس حكمًا قانونيًا بأن كل اقتباس ممنوع، لكنه لا يبرر تسجيل منح نشر شامل لا نملكه. لم نرسل طلب إذن نيابة عن المستخدم.

للعرض الكامل الجاري في النسخة المحلية يلزم نطاق يسمح به؛ إذن مقتطفات محدودة فقط سيحتاج إعداد عرض آخر ومراجعة سياقه، ولا يكفي لتوزيع كامل الكتاب مخفيًا خلف زر. توجد أيضًا مراجعة إصدار علمية وموافقة اللجنة على مصدر المسابقة؛ هذه متطلبات مستقلة عن الحقوق. الإسلام سؤال وجواب قابل للتعطيل في نسخة المسابقة، ولم نثبت اعتماده من اللجنة.

## كيف سيعمل البحث على GitHub Pages؟

1. يحتوي Git على الكود والاختبارات والخطوط ذات ترخيص OFL فقط؛ تبقى `private/` و`var/` والنصوص والفهارس والمفاتيح خارجه.
2. بعد توثيق الإذن واعتماد إصدار المحتوى، يُصدّر كل مصدر في مجلد `data/<source-id>/` مستقل، مع حزم نصية وفهرس لفظي ومتجهات وبصمات وملف `approval.json`. `catalog.json` يحدد المصادر واللغات. لا تُنسخ موافقات وهمية ولا تتحول نسخة research تلقائيًا إلى إصدار عام.
3. تُجهّز حزمة ZIP للمحتوى المعتمد فقط، بجذر يحتوي `catalog.json` و`settings.json` و`vocabulary.json` و`data/`. تُرفع إلى أصل إصدار GitHub Release عام أو رابط HTTPS عام مصرح به. **هذا رفع عام للمحتوى أيضًا** ولو لم يُحفظ داخل Git.
4. يشغّل المسؤول `Deploy approved static Raf` من Actions، ويحدد رابط ZIP وبصمة SHA-256. يتحقق البناء من بصمة التنزيل، ومسارات ZIP وحد الحجم، وحقوق ومراجعة كل مصدر، وبصمات ملفاته. يجهز نموذج البحث وأصول التشغيل المرخصة ثم يرفع ناتج البناء كاملًا إلى Pages.
5. بعد النشر، يطلب المتصفح النصوص والفهارس تدريجيًا من مسار الموقع نفسه. لا يرجع إلى IslamQA أو تراث وقت الإجابة، ولا يحتاج خادم Python أو Docker أو مفتاح API. مع اختيار الإنجليزية لا يُفتح مصدر عربي.
6. لا نعد النشر مكتملًا إلا بعد فتح رابط Pages وتجربة بحث حقيقي بالعربية والإنجليزية، والتحقق من تحميل البيانات والنموذج والإحالات على مسار المستودع.

إذا أُجيز مصدر واحد أولًا، يمكن نشره وحده وتعطيل الآخرين بوضوح. وإذا كان الإذن يسمح بمعالجة خاصة لكنه لا يسمح بتوزيع ملفات النص للمتصفح، فإن GitHub Pages وحده لا يناسب هذا النطاق؛ يلزم حينها خادم وصول وفق الإذن أو مصدر آخر مصرح به. وضع البيانات في رابط مخفي أو مستودع خاص ثم تنزيلها لكل زائر لا يحافظ على سريتها.

لا توجد تكلفة نموذج API في النسخة الحالية. ثقل تنزيل نموذج المتصفح وأصوله يظل قيد أداء ونقل، ويجب اختبار الموقع على الشبكات والأجهزة المستهدفة. [خطوات GitHub](github-setup.md) و[دليل التشغيل المحلي](multisource-runbook.md) يشرحان التشغيل والتحديث.

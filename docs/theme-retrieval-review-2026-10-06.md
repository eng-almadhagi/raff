## ما تغيّر

طُبقت ألوان المرجع العاجية والخضراء والنحاسية، وخطا Amiri وTajawal بترخيص OFL ومحليًا، مع البطاقات والأزرار والمسافات والثيم الداكن. لم تُنقل نصوص القالب أو بياناته. أزرار اللغة والمصادر ظاهرة؛ العربية تبدأ بجميع المصادر، والإنجليزية تبحث حصريًا في IslamQA الإنجليزي. التبديل يحفظ النص المكتوب ويمسح النتيجة والسياق السابقين ويوقف عامل البحث القديم.

أُعيد وزن عنوان الفتوى وسؤالها مع الاسترجاع الدلالي والكلمات، وتوحيد بعض التصريفات والمرادفات، وتمييز السياق الزمني والمكاني ودور السائل. لا توجد خريطة من سؤال الاختبار إلى رقم فتوى أو أجوبة ثابتة. ذِكر موضوع في سؤال متعدد الأجزاء لا يكفي إن لم يتناوله الجواب. تُسترجع النصوص المحفوظة وقت كل سؤال، دون الرجوع إلى المواقع الأصلية أثناء الإجابة.

أصبح جواب المصدر كاملًا هو الاقتباس الرئيسي، داخل مساحة قابلة للتمرير، مع السؤال والسياق والمرجع. بقيت خلاصة الموقع الأصلية منفصلة وموسومة. لا يوجد ملخص توليدي مستقل أو تحويل الحكم إلى فتوى شخصية. هذا يحفظ جميع شروط الجواب المحفوظ، لكنه لا يثبت مناسبة الجواب لكل سؤال أو اكتمال النسخة الأصلية.

- أعادت محاولة HEAD الآلية لـ45 رابطًا رسميًا HTTP 403؛ لم تُسجّل كرابط مكسور أو تحقق ناجح. نجح فتح عينتين عبر أداة الويب: [البخاخ الإنجليزي 78459](https://islamqa.info/en/answers/78459) و[التقسيط 1847](https://islamqa.info/ar/answers/1847). تعذر عرض صفحة تراث ديناميكيًا بهذه الأداة. الإحالات المحلية محفوظة، لكن فحص كل رابط حي بصريًا ما زال غير مكتمل.
- فُحص التصميم على الكمبيوتر وفي إطار بعرض 390px (عرض محتوى 375px، دون تجاوز أفقي)، بالعربية والإنجليزية. ثبت حفظ السؤال ومسح النتيجة عند التبديل. هذا محاكاة عرض هاتف، وليس اختبار جهاز Android/iPhone فعلي أو قياس ذاكرة WASM عليه.

## ما بقي بوضوح

1. الاسترجاع ما زال محافظًا أو غير مركز في بعض الصياغات، خصوصًا اختلاف الفتاوى العام، وأقل ركعات الوتر بالإنجليزية، وفضل صلاة الجماعة. لا تُحتسب هذه الامتناعات دقة كاملة، ولا تعني عدم وجود النص في المصدر. توجد أيضًا نتائج أوسع من المطلوب أو تغطية جزئية موضحة لكل سؤال.
2. محاولات الأسئلة المستقلة الأولى كشفت إخفاقات حقيقية. بعد استخدامها للتحسين أصبحت اختبارات ارتداد؛ لا توجد نسبة نجاح مستقلة عامة يمكن استنتاجها من هذا الحجم. نحتاج بنكًا موسعًا يراجعه مختص، وخاصة انتقال الدور والشرط والاستثناء وتعارض الأقوال.
3. طلب التلخيص لا ينتج شرحًا مبسطًا جديدًا حاليًا؛ يُعيد النص الموثق كاملًا مع التنبيه. لا يوجد مفتاح API أو تكلفة نموذج مدفوع. لا يصدر الموقع حكمًا شخصيًا.
4. التحقق النصي يحافظ على أخطاء النسخة المحفوظة إن وجدت، ولا يصححها بصمت. يلزم مقابلة طبعة موثوقة ومراجعة المختص لمواضع الخلل الأصلي قبل الاعتماد العام.
5. المصادقة على GitHub لم تتم، ولذلك الكود ملتزم محليًا وجاهز للدفع، لكن الرفع غير مكتمل. لا توجد استضافة عامة مختبرة، ولم تُفعّل Pages بواجهة فارغة لإيهام اكتمال النشر.

IslamQA العربي والإنجليزي: توفر حزم رسمية للتصفح دون إنترنت مع عبارة حفظ الحقوق؛ لم أجد ترخيصًا واضحًا يجيز إعادة إتاحتها كاملة عبر رَفّ.

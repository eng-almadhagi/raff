# تجهيز المصادر دون نشر تلقائي

**تحديث 4 أكتوبر 2026:** الأسئلة الشائعة الرسمية تقيد نسخ الموسوعات واستخدامها حتى على جهاز خاص. الجمع وإعادة معالجة المصدر الفعلي متوقفان إلى إذن خاص. انظر [مراجعة الشروط](dorar-rights-review.md) و[مسودة الطلب غير المرسلة](permission-request.md). الأوامر أدناه توثيق للمسار بعد الإذن وليست تصريحًا بتشغيله الآن.

تمت قراءة `https://dorar.net/robots.txt` في 4 أكتوبر 2026: يسمح بالوصول الآلي عبر `Disallow:` فارغة. هذه إشارة وصول تقني، وليست إذنًا بحقوق استخدام النصوص. صفحة API الرسمية https://dorar.net/article/389 تخص الحديث؛ لا توسع هذا التصريح إلى الموسوعة الفقهية.

## المعاينة المحلية المنفذة

جُلبت صفحة الصلاة 1072 للمعاينة فقط. استخرج المحلل 2339 حرفًا و7 حواشٍ من متن المصدر، دون إدخال فقرة الأسئلة والأجوبة اللاحقة في المتن. المسودة محفوظة محليًا في `private/drafts/salah-1072.json` وحالتها pending. لا يُعد هذا فحصًا علميًا أو تحققًا من كامل النطاق.

يحتفظ المحلل بالتشكيل والكلمات ونصوص الحواشي داخل النص الأصلي، مع مواضع start/end للحواشي بدل اختراع أرقام من المصدر. لا يجزئ الحكم عن شرطه أو ينشر المسودة. إذا تغير هيكل HTML يتوقف بدل تخمين متن الصفحة.

```sh
python -m tools.prepare_source private/salah-inventory.json 1072 private/references/salah-1072.html private/drafts/salah-1072.json
python -m raf.cli coverage private/salah-inventory.json
```

أمر coverage ينقل الأعداد فقط إلى قاعدة المنصة، دون نصوص أو روابط فهرس خاصة؛ تعرضها الواجهة منفصلة عن الوحدات المنشورة.

## الجمع بعد وجود إذن موثّق

ملف الإذن الخاص، مثال غير صالح للتشغيل قبل تعبئته ببيانات حقيقية:

```json
{
  "source_origin":"https://dorar.net",
  "book_id":"salah",
  "collection_allowed":false,
  "permission_reference":"",
  "approved_by":""
}
```

لا تضع true لمجرد نجاح قراءة robots أو اعتماد المصدر في المسابقة. ملف الإذن إقرار إداري يستند إلى دليل فعلي؛ البرنامج لا يثبت قانونيته آليًا.

```sh
python -m tools.collect private/salah-inventory.json private/permission.json --limit 10 --interval 3
```

المسار يقبل روابط الحصر نفسها فقط، ويتحقق من الكتاب والمعرف، ويقرأ robots، ويخزن نسخ HTML ومسودات خاصة، ويحفظ حالة كل صفحة. دفعة محدودة إلى 20 صفحة كحد أقصى، بفاصل لا يقل عن ثانيتين، وثلاث محاولات محدودة عند أعطال مؤقتة. عند 401/403/429 يتوقف دون تحايل أو إعادة محاولة. يرفض التحويل إلى نطاق آخر أو صفحة مختلفة وصفحات الحماية، ولا يعتبرها محتوى ناجحًا.

لم يُشغَّل الجمع الشامل لعدم وجود إذن موثّق. اختبارات المسار تستخدم صفحة اصطناعية ومحاكاة أخطاء الشبكة؛ لا ترسل طلبات إلى الدرر.

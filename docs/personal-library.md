# مكتبة الباحث — الإصدار 0.16.0

«إضافة رف» لإدارة الحفظ والكتب، و«مكتبتي» مساحة بحث مستقلة داخل رَفّ. لا تتغير المصادر العامة أو نموذج الاسترجاع بسبب هذا التحديث.

## الاستخدام

1. افتح «إضافة رف»، واختر مكان الحفظ. في المتصفح الداعم، اختر مجلدًا أبًا ليُنشأ داخله Raff، أو اختر Raff الموجود. لا يعرض الموقع مسارًا مطلقًا لا يعرفه المتصفح.
2. سمّ الرف وأضف ملفًا أو عدة ملفات نصية PDF أو DOCX أو TXT أو MD أو JSON. تظهر مراحل الاستيراد والمعالجة والحفظ والتحقق. لا يصبح الكتاب جاهزًا قبل الكتابة وقراءة البيانات المحفوظة للتحقق منها.
3. في «مكتبتي»، حدد الكتب بمربعات الاختيار أو زر الرف أو «تحديد جميع الكتب»، ثم اطرح السؤال. عدم تحديد كتاب يمنع البحث؛ لا يعود إلى المصادر العامة لتعبئة النتيجة.
4. تكبير المكتبة وتصغيرها وإغلاقها إلى الرئيسية يحفظ السؤال والاختيارات والنتيجة في الجلسة. إعادة فتح الموقع تستعيد الكتب والسؤال والاختيارات؛ أعد البحث لعرض النتيجة، دون إعادة رفع الكتاب أو تحليله.
5. صدّر نسخة احتياطية كاملة دوريًا. الاستعادة تدمج الكتب وتكشف التكرار، ولا تمحو المكتبة الحالية.

## الحفظ والاستعادة

- **مجلد Raff:** ملفات أجيال `raff-snapshot-<UUID>.json` تحتوي الكتب ونصوصها ومراجعها والفهرس النصي والمتجهات الدلالية التي أُنتجت. ملف `raff-library.json` يشير إلى الجيل الحالي، و`raff-library.previous.json` إلى السابق. تُكتب نسخة جديدة وتُقرأ وتُفحص قبل تبديل المؤشر. لا تُحذف الأجيال القديمة تلقائيًا؛ لذلك قد يكبر المجلد مع تكرار الحفظ.
- يحتفظ IndexedDB بمقبض المجلد. عند فقد الصلاحية تظهر إعادة الربط/منح الوصول، ولا تُفسّر المشكلة بأنها مكتبة فارغة. تغيير المجلد يفتح مكتبته ولا ينقل القديمة؛ استخدم التصدير والاستعادة للنقل المقصود.
- زر استعادة النسخة المحفوظة يعيد المؤشر السابق بعد فحصه. إذا تعثر أول حفظ ولم يوجد مؤشر سابق، يبحث عن أحدث جيل صالح. لا تحدث هذه الاستعادة تلقائيًا ولا تمحو الملفات الأخرى.
- **الحفظ داخل هذا المتصفح:** بديل IndexedDB واضح الاسم عند غياب دعم اختيار المجلد. يطلب الموقع التخزين المستمر حيث يتاح، دون ضمان الموافقة أو البقاء. مسح بيانات الموقع أو التصفح الخاص قد يفقده. ليس مجلدًا ظاهرًا ولا مزامنة سحابية.
- ترقية قاعدة البيانات إلى الإصدار 3 تحفظ مخازن الكتب والرفوف والمتجهات القديمة، وتستعيدها دون إعادة الاستيراد. إعدادات المتصفح تختلف بين localhost والموقع المنشور، وبين المتصفحات والأجهزة.
- تتضمن النسخة الاحتياطية checksum من SHA-256 وفحص المخطط؛ هذا يكشف التلف ولا يُعد توقيعًا يثبت هوية المؤلف. حد النسخة 150 MB. الكتب والمتجهات لا تُرفع إلى GitHub أو خادم رَفّ.
- يمنع رقم مراجعة الحفظ الكتابة فوق تعديل أحدث في تبويب آخر، ويستخدم Web Locks عند توفره. النسخ المتزامنة في متصفحات مختلفة ليست نظام مزامنة تعاونيًا.

دعم اختيار المجلد يتوقف على المتصفح والسياق الآمن وتفاعل المستخدم؛ يُفحص الدعم فعليًا. انظر [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker) و[توثيق Chrome لحفظ المقابض والصلاحيات](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access).

## المعالجة وحدود البحث

يظل PDF النصي وDOCX حتى 20 MB، وTXT/MD/JSON حتى 5 MB؛ لا OCR ولا ملفات DOC القديمة. مراجع PDF صفحات الملف، ومراجع النص وWord مواضع فقرات، دون اختلاق أرقام صفحات مطبوعة. قد يختل ترتيب PDF ذي الأعمدة أو الحواشي، لذلك تعرض معاينة وتتيح قراءة سياق الكتاب.

الفهرس النصي يُبنى عند الاستيراد؛ المتجهات الدلالية تُبنى تدريجيًا للمرشحين عند الحاجة، وتُحفظ عند اكتمال البحث وفي النسخة الاحتياطية. لا يُدّعى تجهيز كل المتجهات بمجرد رفع الكتاب. التحميل الأول للنموذج قد يتطلب نحو 136 MB؛ المعالجة محلية ولا ترسل السؤال أو الكتاب إلى API، لكن ملفات الموقع والمكتبات والنموذج تحتاج اتصالًا عند التحميل الأول. هذه ليست ضمانة تشغيل كامل دون إنترنت.

الاسترجاع الحالي قد يفوّت إعادة صياغة لا تشترك بألفاظ كافية مع النص. يعرض النص الأصلي ومرجعه، ولا يضمن اعتمادًا شرعيًا أو إجابة صحيحة لكل سؤال. الإنجليزية العامة تظل IslamQA الإنجليزي فقط؛ المكتبة الخاصة تبحث الكتب المحددة باللغة المختارة.

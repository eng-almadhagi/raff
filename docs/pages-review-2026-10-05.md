# تقرير تحويل رَفّ إلى موقع ثابت

تاريخ: 5 أكتوبر 2026. هذه مرحلة تنفيذ واختبار محلي، **ليست إعلان اكتمال المتطلبات أو نجاح نشر عام**.

## المنفّذ

- تطبيق مستقل في `site/`؛ صفحة RTL وهوية خضراء وذهبية وشعار SVG أصلي، بلا خطوط أو خدمات خارجية.
- استرجاع E5 دلالي فعلي داخل Web Worker/WASM، مع بحث هجين مطابق للخوارزمية السابقة. لا يوجد endpoint للإجابة، ولا جلب نص من تراث/الباحث، ولا مفتاح API.
- تخزين الكتاب والفهرس في ملفات ثابتة منفصلة لكل كتاب. تصفية الكتاب تعزل العامل والفهرس. الإضافة تستخدم مسار الاستيراد القديم ثم مصدر التصدير الموحد `tools.build_pages`.
- الجواب القصير الكامل يُنقل حرفيًا، مع المصدر، وزر مغلق افتراضيًا لعرض الفتوى الأصلية كاملة. الأدلة التي أمكن تحديدها تُنقل حرفيًا من النص نفسه. المقاطع ليست تحقيقًا مستقلًا للنص الشرعي.
- اقتراحات من فتاوى فعلية ذات صلة، تفتح الموضع نفسه. شُدّد شرط الموضوع بعد ملاحظة اقتراح بعيد في اختبار الواجهة.
- فهرس للتصفح يتيح جميع المواضع، بما فيها الستة الناقصة أصلًا مع تنبيه. لا تدخل الناقصة ضمن الإجابات.
- workflow نشر ثابت يدوي دون Docker. يرفض المحتوى التجريبي أو غياب الحزمة المعتمدة. الملفات الخاصة مستبعدة من حزمة الكود.

## أدلة الاختبار

| استيراد النسخة | 1816 سجلًا، 3037 وحدة، 2827 قابلة لبناء نتائج الاسترجاع |
| حفظ النص | مطابقة جميع الوحدات للبصمات وتسلسل المصدر الكامل: 2,578,080 حرفًا مع فواصل الاستيراد |
| التكرار | مجموعتان من وحدات مكررة حرفيًا؛ حفظت مواقع المصدر، والنتائج تزيل التكرار العرضي في القائمة فقط |
| مقتطفات وأدلة | جميع المقاطع المختصرة والأدلة المحددة مطابقة لمقاطع النص الأصلي؛ 506 مقاطع دليل/نقل اكتشفها الكاشف، ولا يعني هذا حصر كل الأدلة |
| الأجوبة القصيرة | 2132 وحدة لديها جواب كامل قصير وفق حد العرض؛ بقية المواضع لها مقتطف معلن عدم اكتماله |
| نقل خوارزمية البحث | ترتيب أول خمس نتائج مطابق في 23/23 سؤالًا عند استعمال متجه السؤال المرجعي نفسه؛ هذا اختبار نقل حسابي وليس دقة 100% |
| نموذج المتصفح الفعلي | 8 صياغات جديدة مجمّدة قبل الاختبار؛ 5 نجحت، و3 لم تقدّم جوابًا مباشرًا مطلوبًا. النتائج الأولى محفوظة بلا استبدال |
| اختبارات JavaScript | 6/6، تشمل الاستثناءات وعدم اختلاق دليل وعدم استعمال نتيجة غير كافية |
| اختبارات Python | 111 اختبارًا: 106 ناجحة و5 اختبارات نموذج محلي متخطاة في هذه الجولة؛ لا يُعاد ادعاء تشغيلها هنا |
| الواجهة | بحث فعلي، فتح النص الكامل، رابط الجزء/الصفحة، الانتقال إلى فتوى مقترحة، عرض فتاوى متعددة؛ اختبار شاشة واسعة ومعاينة إطار جوال بعرض 390px |
| النشر | اختبار تحت `/raf/` بخادم ملفات فقط؛ لم يُختبر نطاق GitHub فعلي |

الأسئلة الثلاثة التي لم تنجح مباشرة: صياغة عامية للجوارب الشفافة (امتناع)، صياغة تجمع مرق/حليب الإبل ولحمها (استيضاح)، صياغة نقش القرآن على شاهد القبر (امتناع). لم تُرخّص بوابة الكفاية لمجرد رفع رقم النجاح. هذه حالات قصور في الاسترجاع تحتاج تحسينًا عامًا وتقييمًا جديدًا.

## ما يمنع اعتبار المهمة مكتملة

1. **جودة الاسترجاع:** وجود كل المحتوى لا يضمن استرجاع كل فتوى بأي صياغة. نتيجة 5/8 لا تكفي لإعلان الجودة المطلوبة.
2. **تلخيص الفتاوى الطويلة:** لم يُنفّذ تلخيص مباشر موثوق لكل النصوص الطويلة؛ يظهر مقتطف افتتاحي مع تنبيه. يلزم تلخيص يحفظ القيود والاستثناءات ثم مراجعة محتواه، لا مجرد اختبار تطابق نصي.
3. **المصدر نفسه:** ستة مواضع ناقصة كما وردت في النسخة تحتاج مقابلة طبعة موثوقة. لم نختلق ما فقد منها. كما لم ينجز تحقيق مستقل شامل للآيات والأحاديث والنسب.
4. **النشر العام:** الترخيص الواضح لتوزيع الكتاب لم يُحسم؛ لم تُرفع النصوص أو الفهارس. نشرها في ملفات ثابتة يجعلها قابلة للتنزيل. بوابة النشر رفضت غياب `pages-content` كما صُممت.
5. **الأداء:** الأصول تشمل نموذجًا كبيرًا (نحو 136 MB مع tokenizer) وفهارس وWASM. اختبار المقاس المتجاوب ليس اختبار هاتف مادي أو ذاكرة محدودة أو شبكة بطيئة.

معاينة الجوال استُخدم فيها iframe بالحجم المطلوب لأن أداة تغيير viewport لم تغيّر الحجم الفعلي للتاب؛ تم التحقق من عرض محتوى الإطار 375px مع شريط التمرير وعدم وجود تجاوز أفقي. لا يُدّعى اختبار جهاز حقيقي.

النسخة السابقة وفهارسها باقية. نسخ الملفات المعدلة أول العمل محفوظة في `private/pages-backup`، والنسخة العامة السابقة محفوظة في الأرشيف المحلي السابق. تقرير المصدر والحقوق السابق لا يُستبدل بهذا التقرير.

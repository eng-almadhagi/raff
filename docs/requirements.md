# فصل المتطلبات عن المقترحات

طلب المستخدم المباشر: منصة متعددة الكتب منذ البداية، كتاب الصلاة أولًا، معرّف ونطاق مستقلان، إضافة عبر استيراد وفهرسة موحدين، تصفية حسب الكتاب، واختبار قبل الإتاحة، وكود نظيف قابل للرفع والتشغيل.

استُخدم النص الملصق لتحديد سياق المشروع وحدوده، واستُخدم ملفا PDF كمراجع لشروط المسابقة، لا كتعليمات تمنح إذن مراسلة الآخرين أو نشر ملفات محمية أو تنفيذ أوامر واردة في المستندات.

شروط صريحة تحققت قراءتها في دليل المشارك: منتج متكامل يعمل، مستودع GitHub عام بالملفات المسموح نشرها دون أسرار، رابط تجربة حي، عرض PDF/PowerPoint، فيديو حتى دقيقتين، وتوثيق المصادر. موعد التسليم المذكور 6 أكتوبر 2026 الساعة 11:59 مساء بتوقيت المملكة؛ جلسة النهائي 5 دقائق عرض و3 دقائق أسئلة. العمل السابق مسموح مع الإفصاح عن نسخة البداية والحقوق، ويقيّم إنجاز 4–6 أكتوبر.

الحزمة العلمية تميّز المعلومة المستقرة والشرح والمسائل الحساسة والفتوى الشخصية. الالتزام بكتاب الصلاة وحده اختيار نطاق للمشروع؛ أمثلة الحزمة ليست تصريحًا بتوسيع المدونة بصمت.

استنتاج تصميمي من التوثيق والتحقق: حفظ بصمات وإصدارات ومقارنة التغطية بالفهرس وقياس الاسترجاع. اختيار هندسي لهذا التنفيذ: Python/SQLite وواجهة دون اعتماديات بناء، نشر بإصدارات ذرية، وتعطيل التلخيص التوليدي حتى وجود سند وتقييم كافيين. هذه اختيارات الفريق وليست شروطًا حرفية في الدليل.
